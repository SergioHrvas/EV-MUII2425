## Estructura del proyecto
Dos escenas principales:

- **sillas(abd).tscn**: Escena de los ejercicios entregables A, B y D. Es una habitación con 12 sillas y una cámara orbital asociada a una de ellas. Usa las siguientes escenas y scripts:

    - silla.tscn: Operaciones booleanas entre objetos CSG

    - camera.gd: Script para rotar la cámara horizontal y verticalmente.

- **santuario(c).tscn**: Escena del ejercicio C. Se trata de dos habitaciones y un pasillo. Contiene las siguientes escenas:
    - habitacion1.tscn
        - gancho.tscn
        - bola.tscn
        - silla.tscn
        - plataforma.tscn
        - palanca.tscn
    - habitacion2.tscn
        - escalera.tscn
        - cofre.tscn
